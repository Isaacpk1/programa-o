# Roadmaps semanais

Cada semana tem uma pasta `semana-NN/` com o `roadmap.md` daquela semana.

| Semana | Assunto | Status |
|--------|---------|--------|
| [01](semana-01/roadmap.md) | C++ STL, I/O rápido, tipos e complexidade | Encerrada no Dia 2 (Dias 3-5 movidos para a 02) |
| [02](semana-02/roadmap.md) | Simulação, força bruta, backtracking, recursão + `set`/`map`/`priority_queue` | Planejada |

## Como cada roadmap é montado

- 5 dias de estudo + 2 dias livres para o desafio da semana.
- O plano é montado **a partir do assunto**, nunca do desafio (o desafio é resolvido sem ajuda de IA).
- Cada dia: explicação curta, 3 a 5 exercícios em dificuldade crescente e 2-3 perguntas de revisão.
- Só entram problemas que existem com certeza (CSES, Codeforces, AtCoder, beecrowd), com nome e juiz.
- Para criar uma nova semana, copie `TEMPLATE.md` para `semana-NN/roadmap.md`.
